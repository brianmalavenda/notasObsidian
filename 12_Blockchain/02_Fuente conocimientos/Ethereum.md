**Ethereum: La Plataforma Definitiva de Contratos Inteligentes y Aplicaciones Descentralizadas**

- El "White paper" plantea la necesidad de un mayor control programático sobre las transacciones.
- Buscaba permitir la creación de "corporaciones autónomas descentralizadas" (DAC).
- Introduce la idea de los "Contratos Inteligentes" como una entidad capaz de enviar y recibir criptomonedas, más allá de solo los humanos.

| **Campo / Parámetro**   | **Descripción**                                                                                                                                                                             |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **nonce**               | Cuántas veces el remitente ha enviado una transacción.                                                                                                                                      |
| **to**                  | Dirección de la cuenta a la que va dirigido este dinero.                                                                                                                                    |
| **value**               | Cantidad de "Wei" que se enviará a la dirección de destino.                                                                                                                                 |
| **gasPrice**            | Cantidad de Wei que el remitente está dispuesto a pagar por unidad de gas para procesar esta transacción. Es lo que el minero va a recibir de recompensa por minar un bloque para la cadena |
| **startGas / gasLimit** | Unidades de gas que esta transacción puede consumir.                                                                                                                                        |
| **v, r, s**             | Piezas de datos criptográficos que se pueden utilizar para generar la dirección de la cuenta del remitente. Generadas a partir de la llave/clave privada del _remitente_.                   |
