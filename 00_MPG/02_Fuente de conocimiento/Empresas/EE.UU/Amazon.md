# La interrupción de AWS bloquea Amazon, PrimeVideo, Fortnite, Perplexity y más

20/10/2025

La interrupción de AWS ha derribado millones de sitios web. "Podemos confirmar mayores tasas de error y latencias para múltiples servicios de AWS en la región US-EAST-1. Este problema también puede estar afectando la creación de casos a través del Centro de soporte de AWS o la API de soporte. "Estamos participando activamente y trabajando para mitigar el problema y comprender la causa raíz", señaló AWS.
