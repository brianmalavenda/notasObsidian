Dedicamos 6hs a generar el audio con la api de google de audios largos. Esto genera un archivo .wav que debimos generar la acción para descargarlo del bucket y que se almacene de manera local para poder descargarlo. Esto no sucedió, no quedó guardado en local. Si pudimos hacer que se muestre un reproductor de audio cuando se termina de sintetizar y obtiene de google una respuesta válida.

**Problema**: 
la api se queda esperando a que termine de grabar el audio. Acá el problema es que se convierte en una vulnerabilidad al esperar tanto. Tendríamos que generar una acción de comenzar sinterización de audio y tener otra acción de repreguntar cada X tiempo si el audio ya se generó, en caso que la respuesta sea afirmativa, ahí sí, descargarlo.

**Seguridad:**
Hay que ver el tema de las consultas como viajan hasta la api de google y si el token esta bien que lo dejemos como variable de ambiente o si hay que **"hashearlo"** o crear un secreto de docker como habíamos intentado al prinicipio. Esto quedó pendiente.
