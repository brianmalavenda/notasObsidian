
# Feedly
Es un cliente web con APIs disponibles para consultar. Hasta 100 suscripciones a sitios gratis pero organizadas en 3 carpetas distintas
https://developers.feedly.com/reference/introduction

# NewsBlur

Es de código abierto, permite hasta 64 sitios conectados. Deja organizar los sitios en más de 3 carpetas. Se puede descargar y correr localmente o un VPS
https://newsblur.com/site/576138/the-verge
