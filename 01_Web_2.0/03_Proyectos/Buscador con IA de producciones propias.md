## Detalle

Con la técnica de RAG para el uso de una fuente grande de base de conocimiento a través de una demanda de datos concretos, resúmenes, cuadros sinópticos o líneas de tiempo a través de la generación de texto con un modelo tipo LLM, podríamos buscar en nuestras producciones ideológicas, tanto EJES como informes, folletos, etc, información puntual para “ayudarnos” a base de consulta cuando escribimos una nota en el diario, editorial etc.

## Aportes técnicos

**ORIENTADO A IA**  
Utilizaríamos agentes de inteligencia artificial, interactuaríamos con varios de ellos y nos permitiría avanzar en plataformas como n8n o make para esto. Además de configurar e integrar esto con otras herramientas e incorporar este agente a un sitio web donde utilicemos la CPU local como servidor.
