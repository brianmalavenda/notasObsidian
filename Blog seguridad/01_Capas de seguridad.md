En este documento vamos a definir una serie de pasos de manera de poder ir avanzando en “capas” la privacidad de los ordenadores con los que trabajamos.

# Capa 1: Fase de purga

Requiere pocos conocimientos técnicos y los pasos por cada computadora se realizan una única vez.

# Capa 2: reestructuracion de herramientas

Requiere conocimientos técnicos y los pasos que se describen tienen que tener un seguimiento

# Capa 3: aplicación permanente

Requiere conocimientos técnicos, tiene que tomarse como hábito conciente, de seguimiento constante y atención permanente. Esto requiere una conducta determinada en lo que refiere al comportamiento y el uso de los sistemas informáticos.

# Capa 1

1.       Desvincular documentos y archivos como imágenes o videos de información que querramos que sea privada de las nubes de almacenamiento de Google y Microsoft.

2.       Desinstalar aplicaciones de Windows que realizan telemetría sobre la PC. Es decir, impedir en un primer nivel el registro y envío de uso cotidiano a Microsoft.

3.       Desinstalar antivirus, cualquiera sea. Los antivirus también realizan registro y envíos del uso de la PC a empresas de “data brokers”, quienes venden información de comportamiento (eurística)

4.       Instalar Brave como navegador y empezar a utilizarlo para búsquedas de información de hechos políticos, sobre todo si son “sensibles”. Continuar utilizando GoogleChorme para búsqueda o navegación a portales de noticias de los conocidos

5.       Instalar como extensión y motor de búsqueda predeterminado StartPage en Brave para la privacidad de las búsquedas en la web.
6.       Herramientas: Egosurfing, Deleteme, Justdeleteme, Diseminación desinformativa, Redact, Fake name generator, Incogni

# Capa 2

1.       Instalar una VPN y utilizarla antes de empezar a usar internet (Proton VPN o iVPN o Mullbat)

2.       Usar una CDN distinta a la que te asigna el proveedor de internet

3.       Encriptar contenido de la PC (VeraCrypt)

4.       Mantener el sistema operativo actualizado

# Capa 3

1.       Cambiar el usuario y la contraseña del router

2.       Para búsquedas “mas sensibles” utilizar una conexión tipo Tor

3.       Usar y configurar un firewall (Glasswire o Portmaster)

4.       Usar sistema operativo Whonix en una virtual box
