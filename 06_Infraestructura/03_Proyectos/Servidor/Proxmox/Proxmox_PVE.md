**Proxmox Virtual Environment (PVE)** es una plataforma completa de virtualización de servidores de código abierto de tipo empresarial. Se clasifica como un hipervisor del Tipo 1 (_bare-metal_), lo que significa que se instala directamente sobre el hardware físico subyacente sin necesidad de un sistema operativo anfitrión previo. Basado en la distribución Debian GNU/[[Linux]] y un kernel de Ubuntu modificado, Proxmox integra en una sola solución dos tecnologías de virtualización fundamentales junto con capacidades avanzadas de almacenamiento definido por software (SDS) y redes (SDN), todo gestionado centralmente a través de una interfaz web intuitiva o una interfaz de línea de comandos (CLI) robusta.

El núcleo del funcionamiento de Proxmox PVE radica en su capacidad para unificar la **virtualización completa** mediante KVM (_Kernel-based Virtual Machine_) y la **virtualización basada en contenedores** a través de LXC (_Linux Containers_). KVM actúa como el módulo del kernel que transforma a Linux en un hipervisor, permitiendo ejecutar máquinas virtuales (VM) totalmente aisladas con sistemas operativos invitados heterogéneos (Linux, Windows, BSD), asignándoles hardware virtualizado mediante QEMU. Por otro lado, LXC ofrece un entorno de virtualización ligero a nivel de sistema operativo que comparte el kernel del host, ideal para desplegar instancias de Linux con un consumo mínimo de recursos y una latencia casi nula, optimizando la densidad de computación por nodo físico.

A nivel de infraestructura y persistencia de datos, Proxmox opera nativamente con sistemas de archivos avanzados como **ZFS** y sistemas de almacenamiento distribuido como **Ceph**. Esto permite implementar configuraciones de alta disponibilidad (HA) y tolerancia a fallos de manera nativa, facilitando la replicación de almacenamiento en tiempo real y la migración en vivo (_live migration_) de máquinas virtuales entre nodos de un clúster sin interrupción del servicio. La gestión de redes se realiza mediante puentes virtuales (_Linux Bridges_) configurables y soporte para VLANs, lo que permite segmentar el tráfico de administración, producción y almacenamiento de forma segura y eficiente.

### Ventajas y Desventajas de Proxmox PVE

| **Ventajas**                                                                                                                                                                                                                                  | **Desventajas**                                                                                                                                                                                                                                            |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Licenciamiento Open Source:** Sin costos de adquisición de licencias ocultos ni bloqueos de funcionalidades (_vendor lock-in_), ofreciendo un modelo de suscripción opcional solo para soporte técnico empresarial y repositorios estables. | **Curva de aprendizaje inicial:** Aunque la GUI facilita las operaciones del día a día, la resolución de problemas avanzados o la optimización fina de almacenamiento y redes requiere conocimientos profundos de administración de sistemas Debian Linux. |
| **Dualidad KVM/LXC:** Permite la coexistencia y gestión unificada de entornos robustos y aislados (VM) junto con entornos altamente eficientes y ligeros (Contenedores), maximizando la flexibilidad del hardware.                            | **Soporte oficial limitado:** El acceso a los repositorios de producción más estables (Enterprise) y al soporte técnico directo del fabricante está condicionado al pago de una suscripción por socket, dependiendo el resto de la comunidad.              |
| **Ecosistema Integrado:** Incluye por defecto herramientas de respaldo nativas (con soporte avanzado mediante _Proxmox Backup Server_), firewall programable por cluster/nodo/instancia y soporte nativo para clustering hiperconvergente.    | **Ecosistema de terceros más reducido:** Aunque está creciendo exponencialmente, algunas herramientas comerciales de respaldo, monitoreo o automatización corporativa priorizan la integración nativa con VMware vSphere o Microsoft Hyper-V.              |
