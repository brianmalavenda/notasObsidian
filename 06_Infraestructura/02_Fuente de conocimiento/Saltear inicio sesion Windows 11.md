En la pantalla donde Windows 11 te pide iniciar sesión o conectarte a una red, presiona las teclas **Shift + F10** (en algunas laptops puede ser **Shift + Fn + F10**) para abrir el símbolo del sistema.
Escribe el siguiente comando y presiona **Enter**:    
    
    ```
    start ms-cxh:localonly
    ```   

Se abrirá una ventana clásica para crear una **cuenta local** de usuario.
