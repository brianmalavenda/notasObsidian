## Detalle

Aplicación para celular para registrar el trabajo hecho por cada uno a través de un formulario. Esto se registra en una base de datos centralizada que después se descarga en un archivo Excel, PDF o reporte corto ya unificado con la última actualización al momento.

## Aporte técnico

Es una aplicación web o directamente una aplicación nativa para celular. Ambos caminos aportan una totalidad adaptada luego a cualquier app. El aporte es la traducción de la información en texto plano en la base de datos a un archivo con formato. Puede ser un Excel como base que luego se convierte a pdf o incorporar bibliotecas que permitan hacer gráficos y reportes.
