## Detalle

Una aplicación para hacer llamadas y videos que en un principio aporte facilidad, privacidad para llamadas para reuniones como el ejes, etc.

## Aporte técnico

Acá podemos primero revisar aplicaciones con código abierto como Jitsi para ver como es la lógica para optimizar las conexiones. Esto tiene un aporte técnico de redes, threds. Incorporación de Inteligencia artificial para detectar fallos de conexión, adaptar transmisión de video según velocidad de carga y descarga.
