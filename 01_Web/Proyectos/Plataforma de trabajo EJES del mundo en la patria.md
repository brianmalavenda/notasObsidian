## Detalle

Aplicación que automatiza generar el Word del EJES con los estilos que van. Exportar PDF y unir cuerpo con tapa. Generar audio directamente.

## Aportes técnicos

Nos permitiría utilizar herramientas con IA para automatizar tareas como framework de make.com o n8n. Esto luego debería poder utilizarse desde una aplicación que medie con este framework lo que nos permitiría poder aprender como conectar esa funcionalidad a una aplicación que puede utilizarse desde la web accesible para cualquier miembro del EJES. Habria entonces un módulo de autenticación y autorización.
