Un sistema de comunicación que usa una frecuencia de 800 MHz (ver bien) y que se conecta a otros dispositivos como celulares o tables a través de bluetooth para poder (a través de una app) tener un chat de mensajería. Esto es opcional, sino desde la misma placa se puede hacer.

Con esto se puede armar una red de nodos como repetidores para comunicarse a más distancia que la que nos permite entre dos nodos (1,5 a 2 km) en ambientes casi despejados (ver tambien).

Esto necesita alimentacion por lo tanto tiene que haber alguna forma de que quede conectar a 220 de manera permanente.
