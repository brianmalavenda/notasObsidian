Un [diodo de datos](https://advenica.com/products-and-solutions/data-diodes/ "Diodo de datos") es un dispositivo de hardware que a menudo se denomina "puerta de enlace de seguridad unidireccional". Se coloca entre dos redes con diferentes niveles de seguridad y controla el flujo de información. Un diodo de datos es una solución de ciberseguridad que garantiza que la información solo pueda viajar en una dirección. Dado que las propiedades de seguridad del diodo de datos se basan en hardware y fibra óptica, se puede demostrar que es físicamente imposible que los datos se transporten en la dirección opuesta. Como la seguridad no se basa en software, no existen vulnerabilidades en forma de errores de software, ni puede ser atacado por código malicioso. La seguridad basada en hardware significa que se puede demostrar que los diodos de datos ofrecen una alta fiabilidad.
