Con el comando 

```
	sudo iftop
```

se puede ver el ancho de banda de las comunicaciones entre servicios a través de distintos puertos en mi máquina

con el comando:

```
	sudo ss -tonp
```

se puede ver todos los puertos abiertos en la maquina local , el estado, que IPs son las que estan relacionandose por cada puerto y que aplicacion esta utilizando esa conexion.
