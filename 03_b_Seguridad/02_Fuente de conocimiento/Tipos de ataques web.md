### Phishing y ataques de ingeniería social
Se utilizan para engañar a los usuarios con correos electrónicos o sitios web falsos que imitan a entidades de confianza, con el fin de robar credenciales o información personal.  
 Existen variantes como el vishing (por voz) y el smishing (por SMS).  

### Ransomware
Este tipo de malware cifra los datos del usuario o del sistema, reteniéndolos hasta que se pague un rescate para su recuperación.  
Malware y virus: Software malicioso diseñado para infiltrarse en sistemas, robar información o causar daños, incluyendo gusanos, spyware y adware.  

### Ataques DDoS (Denegación de Servicio Distribuido)
Consisten en inundar un sitio web con un tráfico masivo desde múltiples dispositivos infectados, lo que lo hace inaccesible para los usuarios legítimos.  
Estos ataques pueden clasificarse en volumen, protocolo o de aplicación.  
Limitar la cantidad de solicitudes procesadas por periodo de tiempo. WAFF para proteger del trafico malicioso. Para esto hay de tipo de lista negra y de lista blanca.

### Inyección SQL (SQL Injection)
Permite a los atacantes manipular las consultas a la base de datos de un sitio web, accediendo a información sensible como contraseñas o datos de pago.  

#### Cross-site scripting (XSS)
Permite a los atacantes insertar código malicioso (generalmente JavaScript) en páginas web que luego se ejecuta en el navegador de los usuarios, permitiendo robar cookies, sesiones o redirigir a sitios falsos.  

####  Ataques de falsificación de solicitud entre sitios (CSRF)
Hacen que el navegador de un usuario autenticado realice una acción no deseada en una aplicación web sin su conocimiento, como transferir dinero o cambiar credenciales.  

### Secuestro de sesión (Session Hijacking)
Consiste en robar la cookie de sesión de un usuario para tomar el control de su sesión autenticada.  

### Ataques Man-in-the-Middle (MitM)
Un atacante intercepta y posiblemente altera la comunicación entre un usuario y un servidor web, especialmente en redes WiFi abiertas.  
Whaling: Ataques de phishing dirigidos a altos ejecutivos o personas clave dentro de una organización, con el objetivo de obtener información valiosa.
