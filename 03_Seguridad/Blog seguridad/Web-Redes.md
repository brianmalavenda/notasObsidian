#### Brave - configuracion
1. Es un bloqueador de anuncios por defecto
2. Forzar conexiones HTTPS
3. Bloquear scripts
4. Bloquear cookies de terceros
5. Guardar informacion para mejores configuraciones, desactivarlo
6. Bloqueo de RSSS: Permitir los inicios de sesion de facebook y mensajes inscrustados, desactivarlo
7. Seleccionar porveedor de DNS personalizado. En un principio se puede poner Quad9 (9.9.9.9) o Cloudflare (1.1.1.1)

#### Librewolf - configuracion
1. Tiene un bloqueador de anuncios que es una extension ya instalada que se llama uBlock Origin
2. Buscador predeterminado StartPage
3. Deshabilitar uso de ubicación, camara, microfono, altavoces, bloquear audio y video, bloquear ventanas emergentes por defualt
4. Borrar historial, marcadores, buscadores, accesos directos
5. Activar DNS por HTTPS, revisar si hay alguna web que no entra y temporalmente quitarlo para alguna en particular

#### Mullvad - configuracion
1. Tiene un bloqueador de anuncios que es una extension ya instalada que se llama uBlock Origin
2. Buscador predeterminado StartPage
3. Deshabilitar uso de ubicación, camara, microfono, altavoces, bloquear audio y video, bloquear ventanas emergentes por defualt
4. Borrar historial, marcadores, buscadores, accesos directos
5. Activar DNS por HTTPS, revisar si hay alguna web que no entra y temporalmente quitarlo para alguna en particular
