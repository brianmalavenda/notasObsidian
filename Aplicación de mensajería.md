## Detalle

La aplicación sería una app nativa para celular, posteriormente podría ser una aplicación de escritorio o web como telegram(que se utiliza desde el navegador). Con la aplicación deberíamos poder enviar mensajes de texto, imágenes, audios y archivos. Poder autenticarnos como únicas personas.

## Aportes técnicos

Desarrollo de una aplicación mobile nativa. La autenticación y autorización es uno de los aspectos mas importantes en esta aplicación. Se complejizará cuando la app mobile se expanda a escritorio y web porque una misma sesión deberá poder cargarse en dispositivos distintos y actualizarse en todos a la vez. Conexión con la “nube propia” para guardar el contenido allí. Tiene desarrollo orientado a performance, comunicación de datos, archivos, contenido multimedia. Busqueda en los chats, manejo de historial.
