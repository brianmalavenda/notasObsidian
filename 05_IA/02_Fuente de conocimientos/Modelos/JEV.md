Decisiones estructuradas al instante. Es un modelo de toma de decisiones.
No es determinista, genera una probabilidad de proximidad a la respuesta que tiene mayor "puntaje" respecto al input dado.

Para un sistema de agentes de IA, cada agente puede ser experto en determinado tema en base a una base de conocimiento determinado y un modelo específico. Entonces para una pregunta matemática, JEV puede decidir entre todos los agentes al que se base en el modelo de IA Chat GPT Astra (con que el que se resolvio uno de los problemas del siglo) quizas y el agente llamado, en caso hipotético, "agente_matematica" y derivar la tarea del cálculo a esta IA.
